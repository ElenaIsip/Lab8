# Алгоритм и блок-схема
Инициализация:

Подключить библиотеку <math.h> и определить константу _USE_MATH_DEFINES (для использования математических функций).

Установить русскую локаль (setlocale).

Объявить переменную product типа double и инициализировать её значением 1.0 (так как ищем произведение).

Цикл (от 1 до 100):

Переменная цикла i изменяется от 1 до 100 (включительно) с шагом 1.

Вычислить x=i⋅0.1 

Вычислить текущий множитель: term = 1.0 + sin(x).

Умножить накопленное произведение на текущий множитель: product = product * term.

Вывод результата:

Вывести на экран итоговое значение переменной product.

# Реализация программы

    double product = 1.0; 
    
    // Цикл от 1 до 100
    for (int i = 1; i <= 100; i++) {
        double x = i * 0.1;              // Шаг 0.1 (от 0.1 до 10.0)
        double term = 1.0 + sin(x);      // Вычисление множителя

        product *= term;                 // Накопление произведения
    }

    // Вывод результата (используем %g для компактного вывода)
    printf("Значение произведения: %g\n", product);

    return 0;
